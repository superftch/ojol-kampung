1. Cara Standar: Load Unpacked (.ZIP)

                
    
                    
  1. Unduh ZIP dan ekstrak ke folder komputer.
    2. 
                    
  2. Buka chrome://extensions di Chrome lalu aktifkan Developer mode.
    3. 
                    
  3. Pilih Load unpacked, lalu pilih folder kampungsebelah-extension hasil ekstrak.
    4. 
                    
  4. Buka KampungSebelah dan pilih tab Kendarai di panel ekstensi.
    5. 
                

                📦 Unduh ZIP
            


            

                
2. Opsi Auto-Update: CRX via Enterprise Policy

                

                    Opsional: Chrome memasang .crx langsung dari server dan memperbarui otomatis setiap ada versi baru.
                

                

                    

                        Versi: memuat...
                        Extension ID: memuat...
                    

                    

                        Policy:
                        memuat...
                        
                    

                

                

                    🪟 Windows (.reg)
                    🍎 macOS (.mobileconfig)
                    🐧 Linux (.json)
                    📦 Unduh .CRX
                

                
    
                    
  1. Windows: Unduh .reg, klik dua kali → pilih Yes (Administrator), lalu restart Chrome.
    2. 
                    
  2. macOS: Unduh .mobileconfig dan install di System Settings → Profiles, atau jalankan di Terminal:
    defaults write com.google.Chrome ExtensionInstallForcelist -array-add "..."
    3. 
                    
  3. Linux: Simpan kampungsebelah-helper.json ke /etc/opt/chrome/policies/managed/ lalu restart Chrome.
